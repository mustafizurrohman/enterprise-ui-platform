# Datepicker

The `DatepickerComponent` combines a text input with a modal calendar and time controls. It supports date-only and date-time values, manual entry, paste parsing, Angular forms, and keyboard navigation.

The component derives its mode from the configured Luxon format. A format without time tokens renders a date-only calendar, while time tokens add hour, minute, and second controls.

## Installation

Import the standalone `DatepickerComponent` from `@mr/enterprise-ui/datepicker`. Ensure `@angular/cdk`, Angular Material, and Luxon 3 are available in your project. Include the global CDK overlay styles in your application.

## Basic usage

The component supports Angular signal model binding. User input is normalized to a JavaScript `Date`, and clearing the control sets the value to `null`.

## Forms integration

`DatepickerComponent` supports both reactive and template-driven forms. It implements `ControlValueAccessor` and `Validator`. For form controls, `Date | null` is the preferred value type.
