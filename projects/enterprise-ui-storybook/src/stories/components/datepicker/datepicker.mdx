# Datepicker

The `DatepickerComponent` combines a text input with a modal calendar and time controls. It supports date-only and date-time values, manual entry, paste parsing, Angular forms, and keyboard navigation.

The component derives its mode from the configured Luxon format. A format without time tokens renders a date-only calendar, while time tokens add hour, minute, and second controls.

## Installation

Import the standalone `DatepickerComponent` from `@mr/enterprise-ui/datepicker`. Ensure `@angular/cdk`, Angular Material, and Luxon 3 are available in your project. Include the global CDK overlay styles in your application.

## Basic usage

The component supports Angular signal model binding. User input is normalized to a JavaScript `Date`, and clearing the control sets the value to `null`.

## Forms integration

`DatepickerComponent` supports both reactive and template-driven forms. It implements `ControlValueAccessor` and `Validator`. For form controls, `Date | null` is the preferred value type.

<Canvas of={ReactiveFormStories.ReactiveForm} />

### Forms contract

- **Values**: Accepts `Date`, `string`, `null`, or `undefined`. Emits `Date` on selection or `null` on clear.
- **Parsing**: Valid format, ISO, and SQL strings are parsed. Invalid text remains visible and triggers an `invalidDate` error.
- **State**: The touched callback is called on blur, close, or clear. The component can be disabled via input or form control.
- **Validation**: Does not implement a required rule; use `Validators.required` if needed.

## Public configuration API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | `'Datum auswählen'` | Text in the native `<label>`. |
| `today` | `DateTime` | `DateTime.now()` | Reference date for today state and initial focus. |
| `testId` | `string \| null` | `null` | Prefix for exposed `data-testid` values. |
| `locale` | `string \| null` | `null` | Luxon locale for formatting and labels. |
| `luxonDateFormat` | `string \| null` | `null` | Preferred Luxon format. |
| `dateFormat` | `string \| null` | `null` | Input alias for format configuration. |
| `disabled` | `boolean` | `false` | Disables the component. |
| `showQuickTimeControls` | `boolean` | `false` | Adds quick adjustment buttons in date-time mode. |
| `dateFilter` | `(date: DateTime) => boolean` | `() => true` | Filter for selectable calendar dates. |
| `value` | `Date \| string \| null \| undefined` | `undefined` | Model input for binding. |
