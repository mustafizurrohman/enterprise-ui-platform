# Testability & Integration Standards

The `DatepickerComponent` is designed for seamless integration into enterprise-scale automated testing workflows. It provides stable hooks and adheres to modern Angular testing patterns, ensuring that UI components remain verifiable as the platform evolves.

## Automated Testing Hooks

To insulate test suites from internal DOM changes, the component supports a `testId` input. This value serves as a deterministic prefix for all internal `data-testid` attributes, allowing for resilient CSS or XPath selectors in Unit, Integration, and End-to-End (E2E) tests.

## Architectural Standards

The component's architecture is optimized for modern Angular testing paradigms:

- **Signal-based State Management**: Leverages Angular Signals for granular change detection, simplifying state verification in unit tests.
- **ControlValueAccessor (CVA)**: Fully compatible with `ReactiveFormsModule`, enabling standard `FormControl` state assertions (`dirty`, `touched`, `valid`).
- **Asynchronous Resilience**: Fully compatible with `fakeAsync` and `tick()` for testing overlays, animations, and debounced inputs.
- **Dependency Injection**: Services like `DatepickerParserService` are easily mockable for isolated logic testing.

## Verifying Complex Interactions

### Paste Normalization Testing
When validating the "Intelligent Paste" feature:
1. Dispatch a `ClipboardEvent` of type `paste` to the input element.
2. Verify that the `[data-testid="your-id-input-status"]` live region announces "Eingefügtes Datum übernommen".
3. Assert that the underlying `FormControl` value reflects the correctly parsed ISO or Luxon date object.
