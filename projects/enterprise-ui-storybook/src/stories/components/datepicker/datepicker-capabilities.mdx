# Datepicker capabilities

The datepicker uses a single Luxon format for display, parsing, and mode selection. The model value is a JavaScript `Date`.

<Canvas of={DateTimeStories.DateTime} />

## Format-derived mode

The component automatically adjusts its UI based on the `luxonDateFormat`:
- **Date-only**: No time tokens in the format.
- **Date-time**: Inclusion of time tokens (H, m, s, a).
- **12-hour**: Use of `h` or `hh` adds AM/PM selection.
- **Seconds**: Use of `s` or `ss` adds a seconds control.

Changing the format at runtime updates the placeholder and value representation.

## Formatting and parsing

| Feature | Behavior |
| --- | --- |
| **Placeholder** | Generated from the literal format string. |
| **Manual entry** | Supports smart typing with automatic padding and separator insertion for numeric fields. |
| **Paste** | Normalizes separators and supports Unix timestamps (seconds or milliseconds). |
| **Locale** | Affects months, weekdays, and the hour cycle (12/24h). |

## Supported Luxon tokens

The component supports a wide range of Luxon tokens including years, months, days, time, offsets, and locale macros. Quoted literals are supported for custom separators or labels.

## Common formats

A set of predefined formats is available via `DATE_FORMATS`, including German, ISO, European, and US styles.

## Behavior and interaction

- **Manual Entry**: Committed on blur or Enter. `Uhr` suffix has special case-insensitive handling.
- **Calendar**: Monday-first grid with week numbers. Navigation preserves the selected day when possible.
- **Time Controls**: Text-backed spinbuttons with increment/decrement buttons. Supports quick adjustments (±15/30 mins, ±6/12 hours) if enabled.
- **Filtering**: `dateFilter` disables specific dates in the calendar but does not validate manual input.
- **Actions**: Includes "Today/Now" and "Clear" buttons when enabled and applicable.

## Programmatic values

Accepts `Date`, format-matching strings, ISO strings, or SQL strings. Values are normalized to `Date` during model binding.
