# Datepicker accessibility

The `DatepickerComponent` is designed with ARIA best practices to support screen readers and keyboard navigation.

## Semantic Structure

- **Input**: Exposed as a `combobox` with `aria-haspopup="dialog"`. Includes a visually hidden label suffix for date/time identification.
- **Trigger**: A native button that opens a `role="dialog"` overlay.
- **Overlay**: Uses `aria-modal="true"`, traps focus, and applies the `inert` attribute to background content.
- **Calendar Grid**: Implemented as an ARIA `grid`. Each day is a native `<button>` within a `gridcell`. `aria-selected` and `aria-current="date"` indicate selection and today's date.
- **Time Controls**: Use `role="spinbutton"` with appropriate ARIA value attributes and native increment/decrement buttons.

## Keyboard Interaction

| Key | Action |
| --- | --- |
| **ArrowDown** | Opens the calendar from the text input. |
| **Arrow keys** | Navigate the calendar grid or adjust time spinbuttons. |
| **Home / End** | Move to start/end of the week or min/max time unit. |
| **PageUp / PageDown** | Navigate by month or adjust time by 10 units. |
| **Enter / Space** | Select a date or activate controls. |
| **Escape** | Closes the dialog and restores focus. |

## Focus Management

Focus moves to the selected or today's date upon opening. It uses a roving tab stop for grid navigation and restores focus to the opener upon closing.

## Announcements & Validation

- **Status Regions**: Two `role="status"` regions announce value changes, paste success, and navigation updates.
- **Errors**: Invalid input is associated with error messages via `aria-errormessage` and `aria-describedby`.

## Motion and Color

The component respects `prefers-reduced-motion` for animations and supports high-contrast modes via system colors.

## Consumer Responsibilities

- Provide a concise `label`.
- Note that `locale` localizes dates, not internal UI strings (German).
- Use `dateFilter` and Angular validators for range constraints.
